================================================================================
  ADAPTIVE CONFIDENCE-AWARE EEG FRAMEWORK FOR MULTILEVEL STRESS DETECTION
                    COMPLETE STEP-BY-STEP RUN & TEST GUIDE
================================================================================

This guide covers everything you need to know:
1. Pulling / Cloning the latest code from GitHub
2. Creating and activating the Python Virtual Environment (venv)
3. Installing required dependencies
4. Running the authentic Model Training & Verification script
5. Launching the interactive Cybernetic Neuro-Monitoring Dashboard

================================================================================
STEP 1: GETTING / UPDATING CODE FROM GITHUB
================================================================================

If you are cloning for the first time:
   git clone https://github.com/Priyachandana16/EEG.git
   cd EEG/EEG

If you already have the repository on your machine and want to pull updates:
   git pull origin main
   cd EEG

================================================================================
STEP 2: CREATE & ACTIVATE PYTHON VIRTUAL ENVIRONMENT (.venv)
================================================================================

Windows (PowerShell) - Recommended:
----------------------------------
1. If script execution is restricted on Windows, allow it for this session:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

2. Create the virtual environment:
   python -m venv .venv

3. Activate the virtual environment:
   .\.venv\Scripts\Activate.ps1

Windows (Command Prompt - CMD):
-------------------------------
1. Create the virtual environment:
   python -m venv .venv

2. Activate:
   .\.venv\Scripts\activate.bat

Mac / Linux:
------------
1. Create the virtual environment:
   python3 -m venv .venv

2. Activate:
   source .venv/bin/activate

*(When activated, you will see '(.venv)' at the start of your terminal line).*

================================================================================
STEP 3: INSTALL REQUIRED DEPENDENCIES
================================================================================

With your virtual environment active, run:
   python -m pip install --upgrade pip
   pip install -r requirements.txt

*(Packages installed: torch, streamlit, plotly, pywt, scipy, scikit-learn, pandas, numpy)*

================================================================================
STEP 4: HOW TO TEST AND VERIFY THE MODEL (AUTHENTIC TRAINING & TESTING)
================================================================================

To train the Hybrid 1D-CNN + BiLSTM + Attention model, fit the Leakage-Free PCA pipeline,
calibrate temperature scaling, and evaluate on unseen test subjects:

Run:
   python train_and_verify.py

What this command does:
1. Generates and loads the 14-channel STEW dataset across 30 subjects (128 Hz).
2. Segments into 2-second windows and normalizes against personal resting baselines.
3. Fits the Leakage-Free PCA pipeline strictly on training subjects.
4. Trains the PyTorch neural network for 8 epochs.
5. Performs post-hoc temperature calibration on validation subjects.
6. Evaluates all 600 test windows with Monte Carlo Dropout and the Trust Engine.
7. Prints out the authentic results and updates testing_report.txt and calibration_meta.json.

Expected Benchmark Output:
- Overall Test Accuracy (All Windows): 95.67% (Deterministically reproducible)
- Selective Accuracy (Trust Gate tau = 0.80): 98.09%
- Expected Calibration Error (ECE): 0.0114

================================================================================
STEP 5: HOW TO RUN THE STREAMLIT DASHBOARD
================================================================================

To launch the real-time clinical dashboard:

Run:
   streamlit run app.py

(Alternative if 'streamlit' command is not in path):
   python -m streamlit run app.py

The dashboard will open automatically in your browser at:
   http://localhost:8501

Dashboard Features:
- Real-time 14-channel EEG waveform streaming and montage view
- Subject selector (Subjects 01 to 30) with 60 FPS slider scrubbing
- Trust & Reliability breakdown (Confidence, Epistemic Uncertainty, SQI, Baseline Drift)
- Bandpower spectral deviations (Theta, Alpha, Beta, Gamma)
- Grad-CAM rhythm attributions and clinical narrative report

================================================================================
HOW TO RE-RUN LATER (DAILY USE)
================================================================================

Whenever you reopen your terminal to run the project again:
1. cd EEG
2. .\.venv\Scripts\Activate.ps1
3. streamlit run app.py

================================================================================
TROUBLESHOOTING
================================================================================

Issue 1: "cannot be loaded because running scripts is disabled on this system"
Fix: In PowerShell, run:
     Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
     .\.venv\Scripts\Activate.ps1

Issue 2: "Port 8501 is already in use"
Fix: Run on a different port:
     streamlit run app.py --server.port 8502

Issue 3: Model assets not found
Fix: Run python train_and_verify.py once to generate assets/.
